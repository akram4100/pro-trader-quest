# **TradeMaster Academy: Your Trading Compass**

Build a complete interactive Arabic RTL web application called "TradeMaster Academy".



The goal of this platform is to teach a complete beginner how to become a disciplined and professional trader through short interactive lessons, quizzes, practical exercises, simulations, progress tracking, and an AI trading tutor.



IMPORTANT:

- The platform must NOT be a collection of long articles or videos.

- Learning must be interactive, short, visual, and gamified.

- The user should learn one concept at a time and immediately practice it.

- The interface must be Arabic RTL.

- Use modern professional fintech design.

- Make it responsive and optimized for both Android phones and desktop.

- Use a clean dark/light theme with excellent typography.

- Do not use fake functionality. If a feature requires a backend, implement the backend/database structure properly.



TECH STACK:

- Use the default modern Lovable stack.

- Use Supabase for authentication and database if available.

- Use TypeScript.

- Use a component-based architecture.

- Keep the code modular and easy to expand.
